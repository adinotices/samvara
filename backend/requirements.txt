# Fully pinned, including transitive dependencies.
#
# The direct deps are the four marked below; everything else is pulled in by
# them. They are pinned too on purpose: this service moves real money, and an
# unpinned transitive dep means `docker build` can resolve a different library
# months later and change behaviour with no commit to point at. Pydantic in
# particular already warns that the Field(alias="raise") form used by
# LapseBody is deprecated — the field deciding whether a stake escalates — so
# an unpinned upgrade could silently alter a charge.
#
# To regenerate after changing a direct dep (use python3.12, matching the
# Dockerfile's base image):
#
#   python3.12 -m venv /tmp/lock && /tmp/lock/bin/pip install \
#       "fastapi==X" "uvicorn[standard]==Y" "httpx==Z" "tzdata==W" && \
#   /tmp/lock/bin/pip freeze | sort
#
# Then run the test suite against that venv before committing the result.
